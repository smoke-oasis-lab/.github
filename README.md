# Smoke Oasis Lab community

This repository keeps shared community materials: the organization's GitHub profile, issue forms, and simple guidance for tracking work.

## Task board

Visit the [Smoke Oasis Lab — Community tasks board](https://github.com/orgs/smoke-oasis-lab/projects/1) to see task status. It is available to organization members.

## How we track work

- Use [this repository's Issues](https://github.com/smoke-oasis-lab/.github/issues) for community questions and tasks that are not tied to a product.
- Use the relevant product repository's Issues for product work. [Hookah DB](https://github.com/smoke-oasis-lab/hookah-db) is a public self-hosted REST API catalogue of hookah tobacco.
- Set the native GitHub **Type** and **Priority** fields on every tracked issue. Choose `Task` for concrete work such as maintenance, research, migrations, or documentation; `Bug` for incorrect or unexpected behavior; and `Feature` for a new capability or an improvement to existing behavior, including infrastructure behavior. Priority describes urgency and ordering, not implementation difficulty: `Urgent` for an active incident or critical blocker needing immediate attention; `High` for an important blocker or significant impact that should come before routine work; `Medium` for normal planned work; `Low` for optional improvements or research with no pressing need.
- Labels are optional. Use one only when it adds a useful signal for finding or acting on issues, such as `documentation`, `help wanted`, `good first issue`, or `accessibility`. Do not add `task`, `bug`, or `enhancement` labels because Type already captures that classification.
- Explain what should be done, why it is useful, and how to tell when it is done. For a bug, include steps to reproduce it and the expected result.
- To take a task, comment that you would like to work on it. If you have organization access, assign it to yourself and move it to `In Progress`; otherwise, a member can help with those steps.
- Use the statuses `Todo` → `In Progress` → `Done`. We do not assign automatic deadlines.
- GitHub Free can automatically add items from one repository to a project. Community tasks are added automatically; product issues from other repositories are added manually unless a different setup is configured.
