# Smoke Oasis Lab

We are an informal community of hookah enthusiasts who enjoy building useful IT tools for the things we care about. Programmers and people with hands-on knowledge of hookah, tobacco, and the way people use these tools can all contribute.

We build tools that make information about hookah and tobacco easier to find, check, and use. One public project is [Hookah DB](https://github.com/smoke-oasis-lab/hookah-db), a self-hosted REST API catalogue of hookah tobacco.

## How to help

You do not need to write code. You can try a project and its instructions, share subject-matter knowledge, report something confusing or inaccurate, suggest an idea, or help clarify a task. If you program, you can also take an available task and propose a change.

Browse [tasks available to take](https://github.com/search?q=org%3Asmoke-oasis-lab+is%3Aissue+is%3Aopen+no%3Aassignee&type=issues), or [create a community task](https://github.com/smoke-oasis-lab/.github/issues/new/choose). For Hookah DB, use [its Issues](https://github.com/smoke-oasis-lab/hookah-db/issues/new/choose). The shared [Smoke Oasis Lab — Community tasks board](https://github.com/orgs/smoke-oasis-lab/projects/1) is available to organization members.

To get started, choose an available task and leave a comment saying you would like to take it. If you have organization access, assign the task to yourself and move it to `In Progress`; otherwise, a member can help with that. You can also create a task of your own. You do not need to write code: for example, you can follow the quick-start instructions and report what happened.
